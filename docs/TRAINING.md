# Reproducing the research model

This document reproduces the retained seven-category dermoscopic lesion task. It does not classify rosacea, acne, eczema, arbitrary rashes or smartphone facial photos. `SkinCNN` is trained from scratch; no pretrained backbone or external diagnostic model is substituted for that task. The separate DINOv2 ordinary-photo experiment has [its own source-access/ordered worker instructions](OVERNIGHT_TRAINING.md), [model card](PHOTO_MODEL_CARD.md) and [measured report](PHOTO_EVALUATION_REPORT.md). Do not transfer results between these models or rerun selection on an opened holdout.

## Environment and commands

Use Python 3.13 and create a dedicated environment from the repository root:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.14.1 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-dev.txt
.\.venv\Scripts\python.exe scripts/model_train.py --epochs 50 --seed 20261011
```

The training script downloads the publisher's [DermaMNIST-C release](https://zenodo.org/records/12739457), verifies the advertised checksums, audits split/group overlap and duplicate leakage, trains, selects a checkpoint using validation data, fits temperature using validation logits, and evaluates the held-out test set. **The distributed run completed 50 epochs with seed 20261011 and selected epoch 30.** It produced real weights and executed held-out inference. Read the [model card](MODEL_CARD.md) and [measured evaluation report](EVALUATION_REPORT.md) for the exact result and limitations. Retraining overwrites the distributed artifacts; preserve the existing run separately if you need to compare versions.

Images are CC BY-NC 4.0 and metadata CC BY 4.0. Honor the attribution and noncommercial terms. The corrected splits use lesion grouping. Patient identifiers are not supplied, so patient-level independence is not established. The pipeline performs additional exact/near-duplicate checks; read the audit output rather than assuming all possible leakage is removed.

## Verify the installed run without training

```powershell
.\.venv\Scripts\python.exe -m pytest backend/tests -q
.\.venv\Scripts\python.exe scripts/model_verify.py
```

The normal verifier checks checkpoint/ONNX digests, ONNX graph structure, manifest/report/CAM consistency and every saved test metric, then executes genuine PyTorch inference on the three licensed demo images. It regenerates `models/browser_parity.json` from that execution; no saved scores are used as a substitute for model inference.

For a stronger reproduction check, download the documented source files if they are absent, then execute frozen weights across the entire retained test partition:

```powershell
.\.venv\Scripts\python.exe -c "from scripts.model_train import download_data; download_data()"
.\.venv\Scripts\python.exe scripts/model_verify.py --recompute-heldout
```

This verifies `dermamnist_corrected_28.npz` MD5 `96e2862980877d45d9cacb5c25de6950` and `DermaMNIST-C.csv` MD5 `1c54bc9f483e97a9d7dbbde076a45900`. It reproduces lesion/similarity exclusions, split counts, the complete image/split hash manifest and training-set mean/std, runs all 1,218 held-out inputs and compares fresh logits with stored outputs. This check completed successfully for the installed run; it does not fit weights or alter evaluation results.

## Actual run procedure

The pipeline uses the release's fixed partitions and asserts no known lesion-ID overlap. Before fitting, it checks exact SHA-256 RGB28 pixel hashes and candidate near duplicates using a 64-bit difference hash (Hamming distance ≤2) plus RGB mean absolute difference ≤12. A match purges the whole affected held-out lesion. Four matched pairs caused nine test-image removals; retained counts are train 8,215, validation 573 and test 1,218. This conservative check is not exhaustive and is not proof of patient independence.

Normalization is derived only from training images. Training uses batch size 128, normalized square-root inverse-frequency class weights, weighted cross-entropy, AdamW (learning rate 0.003, weight decay 0.0001), cosine scheduling to 0.0001, flips and 90-degree rotations. Python, NumPy, the DataLoader and PyTorch use the stated seed; deterministic PyTorch algorithms are enabled. The recorded run used four CPU threads, PyTorch 2.14.1+cpu and NumPy 2.5.4. Identical versions/platform are needed for the strongest numerical reproduction; deterministic settings do not guarantee identical results across all runtimes.

Validation macro-F1 selects the checkpoint. Validation NLL selects temperature 0.8 on a fixed 0.5–5.0 grid in 0.025 steps; the same partition serves both purposes. The score/margin rejection values (0.65 and 0.15) are fixed research heuristics. After selection, held-out inference produces the measured report; no test-driven weight, calibration or threshold fitting occurs. Subsequent verification reuses frozen weights and outputs only.

Demo examples are exported from the first retained test image for label indices 5, 4 and 1, independent of predictions. Their source IDs, reference labels, attribution, noncommercial license and selection method are in `public/demo/manifest.json`. An uncertain demo result is retained honestly. The three examples remain in the measured test partition and do not provide additional independent validation.

## Evaluation interpretation

Report macro-F1, balanced accuracy, per-class recall, class support, confusion matrix and calibration as measured. Calibration on a research validation set does not create medical probabilities. Describe the sample sizes and score/rejection behavior. Abstention thresholds are documented research heuristics, not validated clinical operating points.

Subgroup evaluation can only use labels actually present. If skin-tone or patient identifiers are absent, mark that evaluation unavailable instead of estimating them from images. The 28 × 28 benchmark loses important fine detail. Source population, devices, class balance and image acquisition limit external generalization; no external clinical validity is claimed.

Run the backend tests after training to exercise actual model loading and inference. The browser E2E runs the exported ONNX model on a licensed example. A passing schema test or a healthy endpoint alone does not prove a classifier works.
