# 90-second technical demo

Rehearse against the actual deployed build and actual trained artifact. This script assumes model loading/inference has been verified. If weights cannot load, show the unavailable state and say so; do not use a prerecorded prediction as a live response. Use a licensed held-out example from the app, never a person's private image.

Before recording, confirm those measurements still match the displayed model version and saved report, and read each price's checked date and exact package size. The current snapshots are US retail listings dated October 12, 2026; recheck the seller before presenting them as current prices. Prefer a licensed assessed example to demonstrate label-specific education; if the actual run is uncertain, show the genuine generic unable-to-assess guidance instead. Never call an image benign, safe or all-clear based on this demo. A model/category mismatch is an instructive limitation, not a reason to manufacture a better result. The classifier is for dermoscopic images and cannot identify acne, rosacea, eczema or skin type from a selfie.
